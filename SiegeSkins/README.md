# Siege Vault

Локальный концепт-каталог скинов в dark danger стиле на ASP.NET Core.

## Запуск

1. Установите .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
2. В терминале перейдите в папку проекта.
3. Выполните `dotnet run`.
4. Откройте `http://localhost:5080`.

Для быстрого просмотра интерфейса без установленного .NET SDK можно запустить
`powershell -ExecutionPolicy Bypass -File .\preview.ps1`.

Проект является неофициальным фан-концептом и не связан с Ubisoft.
